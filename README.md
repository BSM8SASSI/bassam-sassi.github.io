# Bassam Sassi Portfolio Website

## 🚀 How to Upload to GitHub Pages

### Step 1: Download the ZIP file
Download `bassam-sassi-website.zip` and extract it.

### Step 2: Upload to GitHub
1. Go to your GitHub repository: `BSM8SASSI/bassam-sassi.github.io`
2. Click **"Add file"** → **"Upload files"**
3. Drag and drop ALL files from the extracted folder
4. Click **"Commit changes"**

### Step 3: Add Your Photos
You need to add your DeepLook photos to the `images/` folder.

**Rename your photos to these exact names:**

| Your Photo | Rename To | Used In |
|------------|-----------|---------|
| SOLIDWORKS CAD screenshot | `deeplook-cad.jpg` | Gallery |
| Top view of prototype | `deeplook-prototype-top.jpg` | Gallery, Projects |
| Side view of prototype | `deeplook-prototype-side.jpg` | Gallery |
| Electronics close-up | `deeplook-electronics.jpg` | Gallery |
| Raspberry Pi board | `deeplook-raspberry.jpg` | Gallery |
| Testing setup | `deeplook-testing.jpg` | Gallery |
| Workstation photo | `deeplook-workstation.jpg` | Gallery |
| Waterproofing test | `deeplook-waterproof.jpg` | Gallery |
| Airfoil prototype | `airfoil-dfam.jpg` | Projects |
| 3D printer photo | `3dprinting-optimize.jpg` | Projects |
| Wireless control board | `wireless-control.jpg` | Projects |
| Naval maintenance | `naval-maintenance.jpg` | Projects |
| Your portrait photo | `profile.jpg` | About (optional) |

### Step 4: Wait for GitHub Pages
Your site will be live at:
```
https://bassam-sassi.github.io
```

It may take 2-5 minutes to activate after uploading.

## 📝 To Customize

1. **Edit text**: Open any `.html` file in a text editor
2. **Change colors**: Edit `css/style.css` → `:root` variables
3. **Add photos**: Upload to `images/` folder with correct names
4. **Update links**: Edit email, LinkedIn, GitHub in `contact.html`

## 🆘 Need Help?

If something doesn't work:
1. Check that file names match exactly (case-sensitive)
2. Make sure `index.html` is in the root folder
3. Verify images are in the `images/` folder
4. Wait 5 minutes for GitHub Pages to update
