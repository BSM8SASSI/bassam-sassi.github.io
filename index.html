Technical Highlights

What Makes DeepLook Special

⚙️

6-DOF Thruster Configuration

Custom-designed thruster nozzles with 6-motor configuration enabling full 6-degree-of-freedom movement: surge, sway, heave, roll, pitch, and yaw.

CAD Design Hydrodynamics
🔒

Advanced Waterproofing

Custom waterproof capsules for electronics with hydrostatic pressure testing. Designed to withstand underwater environments while maintaining signal integrity.

Waterproofing Testing
🎮

PS4 Controller Integration

Wireless control via PS4 controller with serial communication protocol. Low-latency response for precise underwater maneuvering.

Embedded Serial Comm
🧠

Raspberry Pi + Arduino

Hybrid control architecture: Arduino Nano for real-time motor control, Raspberry Pi for high-level processing and data acquisition.

Python C/C++
🖨️

3D Printed Components

All structural components designed in SOLIDWORKS and manufactured via FDM 3D printing. DFAM optimization achieving 60% mass reduction.

SOLIDWORKS 3D Printing

Flow simulation analysis for drag coefficient optimization, velocity vector analysis, and acoustic signature reduction using SOLIDWORKS Flow Simulation.
